# doorprize-app (nama sementara)

Aplikasi undian doorprize untuk event corporate, dengan tampilan show di LED/proyektor. Operator menyiapkan sesi, hadiah, dan peserta, lalu menjalankan undian cukup dengan tombol **NEXT** (keyboard atau clicker presentasi).

**Status:** tahap persiapan. Belum ada kode aplikasi.

## Dokumen

- [`docs/keputusan.md`](docs/keputusan.md): arah produk, keputusan, fitur yang ditunda, dan urutan kerja
- [`CLAUDE.md`](CLAUDE.md): ringkasan proyek dan aturan kerja untuk Claude Code

## Struktur

| Folder | Isi |
|---|---|
| `docs/` | Keputusan, spesifikasi adegan, catatan teknis |
| `app/` | Kode aplikasi (menyusul setelah teknologi dipilih) |
| `assets-video/` | Template video background (dikerjakan terpisah) |
| `reference/` | Prototipe lama, hanya untuk referensi teknik |
