# assets-video/

Template video background (MP4 looping + bumper opener) yang dikerjakan di sesi terpisah. Nantinya masuk sebagai template tambahan/premium, di luar 3 template generatif bawaan aplikasi.

Arahan lengkap: [`docs/arahan-aset-video.md`](../docs/arahan-aset-video.md). Sesi aset video tidak mengubah kode aplikasi.

```
assets-video/brief/          dokumen arahan
assets-video/source/         file project/kode animasi (bisa dirender ulang)
assets-video/styleframes/    style frame untuk persetujuan
assets-video/previews/       contact sheet & preview uji keterbacaan (ukuran kecil)
assets-video/renders/        file final MP4/PNG (Git LFS atau di luar git, belum diputuskan)
```

Video final jangan di-commit sebagai file git biasa.
